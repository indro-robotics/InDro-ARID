# arid_drone_description

## Launching the XACRO with Rviz
To launch the robot description with RVIZ for visualization, use ros2 launch.

``ros2 launch arid_drone_description arid.launch.py``

## Launching XACRO without RViz
To launch the robot description TF tree without RVIZ, use ros2 launch

``ros2 launch arid_drone_description xacro.launch.py``
